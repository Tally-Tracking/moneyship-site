# moneyship.app

The MoneyShip website, served by GitHub Pages: the home page, the privacy policy, the terms, support, account deletion, the public list of analytics events, and the pages that the sign-up and password-reset emails open.

MoneyShip was previously called Tally; the old address, tallytracking.app, forwards here.

- Plain HTML, CSS and JavaScript. No build step.
- `npm test` checks the account-email pages' logic (`auth-link.js`) with Node's built-in test runner.
- The app itself lives in a separate, private repository. Nothing private belongs here: everything in this repository is public.
- Fonts: DM Sans (SIL Open Font License, `fonts/DMSans-OFL.txt`).
